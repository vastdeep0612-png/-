## 실제로 확인할 수 있는 구현

- **반응형 웹 UI:** PC와 모바일에 맞춘 메뉴, 카드, 폼 레이아웃
- **인터랙션:** 상품 카드가 스크롤에 따라 등장하며, 모션 감소 환경을 지원
- **테마:** 라이트·다크 모드 전환과 페이지 간 선택 상태 유지
- **회원·문의:** Supabase 인증 연동 및 회원별 문의 내역 조회 구조
- **접근성:** 키보드 포커스, 입력 오류 안내 등 기본 사용 흐름 반영

위 항목은 MODERUN 자체 사이트의 구현 내용입니다. 타사 고객 프로젝트나 검증되지 않은 성과 수치를 의미하지 않습니다.
